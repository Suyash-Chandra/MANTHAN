# Dataset register

No external dataset is bundled in this repository.

| Dataset | Intended task | Status |
| --- | --- | --- |
| SeabedObjects-KLSG / Kaggle challenge | Bounding-box detection | Adapter target; confirm downloaded license and provenance first. |
| AI4Shipwrecks | Shipwreck segmentation | Adapter target; keep every wreck site entirely in one split. |
| AquaScan-1K | Human-target detection | YOLO labels; record is marked copyright, so do not bundle or train without permission. |
| Roboflow Side Scan Sonar | Ship/plane detection | Optional; validate version-specific export and licensing terms. |

NOAA references inform workflow only and are not treated as training data.
